# 智能工作台
一个自动化合成辅助 Minecraft 模组，新增方块：智能工作台。

## 📖 概述
智能工作台可以自动探测并连接周围箱子等存储容器。打开GUI后，右侧面板会自动列出当前所有接入存储内材料能够合成的全部物品，不用手动计算、翻找材料。

## ⭐ 特色功能
- **链式下级合成**
材料不足时，工作台自动检索缺少的材料是否可以合成半成品。确认后逐级自动合成中间产物，直接产出目标物品，省去反复手动合成半成品的麻烦。

- **批量合成**
支持自定义批量合成数量；Ctrl + 左键快速批量合成。可在配置开启：持续合成直到材料耗尽。

- **挂机自动合成**
Alt + 左键点击物品，设置为自动合成目标，工作台会持续产出，产物直接送入指定输出容器。

- **扳手手动绑定容器**
手持扳手 Shift+右键切换绑定模式，分别绑定**提取（材料来源）容器**和**输出容器**，自由管理输入输出。

- **同类物品折叠**
类似 REI 的折叠效果，同类物品折叠在一起（例如不同材料的楼梯、头盔），点击展开列表选择要合成的物品。

- **拼音搜索**
物品列表太多时支持搜索，**拼音也能搜**，找配方很方便。

- **一键清空**
一键清空合成栏，所有物品自动退回原来的存储容器，保持界面整洁。

## ✅ 兼容性
- 兼容配方查看器：REI / JEI / EMI
  在工作台界面，直接从 REI/JEI/EMI 打开配方，就能调用智能工作台进行合成。
- 兼容 [精妙背包](https://www.mcmod.cn/class/3739.html)
  可以读取绑定箱子里的精妙背包，也能读取范围内玩家物品栏、穿戴的精妙背包物资。玩家侦测范围默认 3×3×3，最大 50×50×50。
- 兼容 [精妙存储](https://www.mcmod.cn/class/6711.html)
  自动扫描范围内精妙箱子，也支持用扳手手动绑定精妙箱子作为输入/输出容器。
- 兼容 [多态合成](https://www.mcmod.cn/class/2895.html)
  同一个成品存在多个配方时，界面会出现切换按钮，自由选择配方进行合成。

## ✨ 基础操作
- 左键：把材料填入合成栏
- Shift + 左键：直接合成物品
- Ctrl + 左键：批量合成
- Alt + 左键：设置挂机自动合成目标
- 空格 + 左键：展开/收起折叠物品组
- 手持扳手 + Shift + 右键：切换输入/输出绑定模式

## ⚙️ 配置项
### 存储接入相关
- 容器自动搜索范围：默认 5×5×5，最大 50×50×50
- 输入、输出容器绑定上限：1 ~ 50，分开配置
- 配方列表最大显示数量：默认 8192，范围 12 ~ 32768；旧配置小于等于1024会自动兼容为8192
- 自动扫描容器数量上限：默认 6，1~24
- 黑名单：可以设置不接入的容器类型
- 读取玩家精妙背包范围：默认 3×3×3，1~50
- 多人开关：是否读取其他玩家的精妙背包（默认关闭）

### 合成行为相关
- 自动合成单次上限：默认64，范围1~12138
- 批量合成耗尽模式：开启后忽略数量，一直合到材料不够（默认关闭）
- 是否在列表显示链式合成项目（带链标记）：默认开启
- 链式合成追溯层数：默认16，1~64
- 链式合成单次最多补做中间产物份数：默认256，4~4096
- 链式规划节点上限：防止复杂配方炸服，默认200000，1000~20000000
- 链式项目材料复核预算：0=关闭复核，默认100000，0~5000000
