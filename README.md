# Smart-workbench
自动侦测附近容器，一键提取材料合成。Auto-detect nearby containers for one-click material extraction and crafting

智能工作台 Smart Workbench
一款高度自动化、可高度自定义的 Minecraft 合成辅助模组
极简全自动合成体验，支持容器联动、链式递归合成、挂机自动产线、精妙背包全兼容、主流配方模组互通，彻底解放双手，优化原版繁琐的合成流程。

📌 模组简介
本模组新增智能工作台方块，支持自动扫描并联动周围存储容器，无需手动取放材料。内置可视化合成UI、多级链式合成、无人值守自动合成、输入输出容器分离绑定，同时完美兼容 JEI / REI / EMI 配方模组与精妙背包模组，是生存、大型资源量产、自动化基地必备辅助模组。

✨ 核心功能
1. 容器自动联动 · 可视化合成UI

   智能工作台可自动侦测并连接范围内所有箱子容器，打开GUI即可预览所有可合成物品。点击物品即可自动从绑定容器提取材料填充合成网格，无需手动翻箱、取物、摆配方。
3. 丰富快捷合成按键
- 左键单击：自动提取材料，填充合成配方
- Shift + 左键：一键单次快速合成
- Ctrl + 左键：连续批量合成物品
- Alt + 左键：设置挂机自动合成目标
3. 链式递归合成（自动补半成品）

   行业级特色功能！合成目标物品材料不足时，工作台会自动检测缺失材料是否可合成。确认后自动逐级合成所有中间半成品，从原材料到成品全自动补齐，无需手动分步合成。
4. 无人值守挂机自动合成

   使用 Alt+左键 设置合成目标后，玩家离开工作台、关闭GUI依旧可以持续自动合成。支持绑定专属输出箱子，实现全自动量产流水线。
5. 扳手高级绑定 · 输入输出分离

   模组自带专用扳手，支持自由绑定容器模式：
- 扳手 + Shift + 右键：切换「输入容器绑定 / 输出容器绑定」模式
- 支持材料输入箱、成品输出箱分离配置，搭建规整的自动化产线
6. 全维度可自定义配置

   所有检测范围、绑定上限均可自由修改，适配小型生存与大型服务器量产场景：
- 容器扫描范围：默认 5×5×5，最大支持50×50×50
- 输入/输出容器绑定上限：1–50 可调
- 玩家背包检测范围：默认 3×3×3，最大 50×50×50
7. 完美兼容 精妙背包

   全方位适配精妙背包模组，打通所有物资来源：
- 可读取、提取、使用绑定箱子内存放的精妙背包中的物资
- 可读取、提取、使用玩家身上穿戴、物品栏存放的精妙背包物资
- 仅读取自定义范围内玩家的背包物资，精准可控、防止串档
8. 全主流配方模组兼容

   原生完美兼容 JEI / REI / EMI 三大物品配方模组。

   在智能工作台界面内，直接打开任意配方，即可一键调用工作台合成能力，查配方、合成一步到位，操作丝滑无缝。
9. 同类物品折叠功能

   类似REI的折叠功能，可合成列表中同类物品会折叠在一起，比如楼梯头盔等不同材料的相同类物品会折叠成一种，点击可以打开折叠列表，选择合成物品。

10. 拼音搜索框
   
    当可合成列表物品太多时，可使用搜索框进行搜索要合成的物品，支持拼音搜索，简单便捷。

⌨️ 快捷键总览
- 左键单击物品：自动填充合成材料；
- Shift + 左键：快速单次合成；
- Ctrl + 左键：批量连续合成；
- Alt + 左键：设置挂机自动合成目标；
- 空格 + 左键点击：折叠列表物品开关；
- 扳手 + Shift + 右键：切换容器输入/输出绑定模式。

⚙️ 可配置参数
可在配置文件中自由调整：
- 容器三维搜索范围
- 输入、输出容器最大绑定数量
- 玩家精妙背包检测范围
