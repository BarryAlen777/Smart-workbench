# Smart-workbench
自动侦测附近容器，一键提取材料合成。Auto-detect nearby containers for one-click material extraction and crafting

Smart Workbench
A powerful, fully configurable automatic synthesis mod for Minecraft. Adds a new Smart Workbench block with container linking, auto-crafting, recursive crafting, full inventory/backpack support, and compatibility with mainstream inventory & recipe mods.

---
✨ Features
1. Auto Container Connection & Visual UI
The Smart Workbench can automatically detect and connect nearby storage containers. The built-in GUI displays all craftable items based on your stored resources. One-click to fill recipes from linked containers without manually picking up items.
2. Rich Crafting Keybind Controls
- Left Click — Extract materials and fill the recipe grid
- Shift + Left Click — Instant single craft
- Ctrl + Left Click — Batch craft continuously
- Alt + Left Click — Set target item for AFK auto crafting
3. Recursive Chain Crafting (Auto Craft Intermediate Items)
If the target item lacks raw materials, the workbench will automatically detect missing ingredients that can be crafted. After confirmation, it recursively crafts all intermediate items until the final target item is completed. No more manual step-by-step crafting.
4. AFK Offline Auto Crafting
After setting a crafting target with Alt + Left Click, the workbench continues auto-crafting even when you leave the GUI or move away. Supports dedicated output containers for fully automated production lines.
5. Wrench Container Binding System
Use the mod-provided wrench to bind containers manually.
- Shift + Right Click — Switch binding mode: Input Container / Output Container
- Separate material input storage and product output storage to build clean automation pipelines
6. Full Customizable Range & Limits
- Container scan range: Default 5×5×5, max 50×50×50
- Bound container limit: 1–50 (configurable for both input and output)
- Player detection range: Default 3×3×3, max 50×50×50
7. Sophisticated Backpack Compatibility
Fully supports Sophisticated Backpacks:
- Reads and uses items inside backpacks stored in linked containers
- Reads and uses backpacks in player inventory or worn on the player
- Only players within the configurable range will have their backpack resources detected
Unifies chest storage + player portable backpack resources for crafting.
8. Full Recipe Mod Compatibility
Native support for JEI / REI / EMI.
Inside the Smart Workbench GUI, you can directly open recipes from these mods and start crafting instantly. Query recipes and craft in one interface seamlessly.

This mod aims to completely optimize Minecraft’s cumbersome crafting process. It realizes container resource integration, recursive automatic crafting, AFK production, backpack resource reading, and full compatibility with mainstream recipe mods. Perfect for survival, large-scale resource processing, and automated base production.

📌 模组简介
本模组新增智能工作台方块，支持自动扫描并联动周围存储容器，无需手动取放材料。内置可视化合成UI、多级链式合成、无人值守自动合成、输入输出容器分离绑定，同时完美兼容 JEI / REI / EMI 配方模组与精妙背包模组，是生存、大型资源量产、自动化基地必备辅助模组。

---
✨ 核心功能
1. 容器自动联动 · 可视化合成UI
智能工作台可自动侦测并连接范围内所有箱子容器，打开GUI即可预览所有可合成物品。点击物品即可自动从绑定容器提取材料填充合成网格，无需手动翻箱、取物、摆配方。
2. 丰富快捷合成按键
- 左键单击：自动提取材料，填充合成配方
- Shift + 左键：一键单次快速合成
- Ctrl + 左键：连续批量合成物品
- Alt + 左键：设置挂机自动合成目标
3. 链式递归合成（自动补半成品）
行业级特色功能！合成目标物品材料不足时，工作台会自动检测缺失材料是否可合成。确认后自动逐级合成所有中间半成品，从原材料到成品全自动补齐，无需手动分步合成。
4. 无人值守挂机自动合成
使用 Alt+左键 设置合成目标后，玩家离开工作台、关闭GUI依旧可以持续自动合成。支持绑定专属输出箱子，实现全自动量产流水线。
5. 扳手高级绑定 · 输入输出分离
模组自带专用扳手，支持自由绑定容器模式：
- 扳手 + Shift + 右键：切换「输入容器绑定 / 输出容器绑定」模式
- 支持材料输入箱、成品输出箱分离配置，搭建规整的自动化产线
6. 全维度可自定义配置
所有检测范围、绑定上限均可自由修改，适配小型生存与大型服务器量产场景：
- 容器扫描范围：默认 5×5×5，最大支持50×50×50
- 输入/输出容器绑定上限：1–50 可调
- 玩家背包检测范围：默认 3×3×3，最大 50×50×50
7. 完美兼容 精妙背包
全方位适配精妙背包模组，打通所有物资来源：
- 可读取、提取、使用绑定箱子内存放的精妙背包中的物资
- 可读取、提取、使用玩家身上穿戴、物品栏存放的精妙背包物资
- 仅读取自定义范围内玩家的背包物资，精准可控、防止串档
8. 全主流配方模组兼容
原生完美兼容 JEI / REI / EMI 三大物品配方模组。
在智能工作台界面内，直接打开任意配方，即可一键调用工作台合成能力，查配方、合成一步到位，操作丝滑无缝。
